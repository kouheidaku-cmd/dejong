## 実際の口座を surge で運用する (2026-11-14、人の決定)
人の決定 (「surgeでいく」)。目標は「4か月で +20%、多少のリスクは許容」。
- 実際の口座の注文案は、`surge/` (米国株の集中モメンタム、上位5銘柄、週1回入れ替え) が出す。定期実行も surge-trade に切り替えた
- `config/rules.yaml` (v3) は書き換えていない。v3 と候補 (swap-gap20・atr3・v4-draft) はフォワードテストで記録を続け、2027年1月下旬に見直す
- 開始時点の 株 + 現金 は 405,316円 (11/13 終値)。目標は 2027-03-14 までに 486,379円
- 承知のうえで受け入れたリスク (`surge/README.md`): 過去21年の検証で、4か月で +20% 以上は 21%、マイナスは 31%、最大下落 37%。保有はすべてドル建てになる
- 切り替え型 (市場の状況で v3 と surge を切り替える) は検証して採らなかった (`reports/surge/2026-11-14-switch/report.md`)
- 見直しの線として、株 + 現金が 324,000円 (-20%) を割ったら注文案を止めて相談することを提案した
- `config/strategy.md` は v3 の説明のままなので、人が書き直すまで、実際の口座の説明としては `surge/README.md` を読む

  - `phases --until` (古い期間だけで確かめる)
- 2005〜2018年 (これまでの案が使っていなかった期間) の結果: 入れ替えは 12通り中11通りで v3 よりリターンが高く、各年の最大下落の平均は +1.8ポイント。

## 設定と基準の変更 (2026-11-10、rules.yaml は v3 のまま)
人の了承 (「全部おすすめで」) による。根拠は `reports/rules/2026-11-10-review.md`。
- **ドローダウン停止**: やめた (`settings.yaml` の `max_drawdown_pct: null`、人の判断)。
  以前の作りは、止まったあと現金だけになると二度と再開できなかった (8年の検証で 2020年3月から停止したまま、-9%)。
  「直近365日の最高値」から測るように直しても、停止なし +128% に対して +71% で、最大下落も小さくならなかった。
  ドローダウンの表示は直近365日の最高値からに変えた。バックテストは今までどおり停止なしなので、以前のレポートと比べられる
- **採用の基準**: 4基準 (プラスの年 6/8 など) と「シャープレシオが現行以上」「2ポイント以内」をやめ、
  12通りの年の区切りでの現行ルール・同じ持ち高の指数との比較に変更 (`python -m trader phases`、`strategy.md` の「ルールの直し方」)
- **口座の作り**: コア (指数の投資信託) とサテライト (このシステム) に分ける。今の株の口座をそのままサテライトにし、これから入れるお金はすべてコアへ (コアが7割になるまで)
- 別枠 (sleeves) と押し目買い (`entry.mode: dip`) の仕組みをコードに追加 (採用はしていない。`reports/rules/2026-11-10-dip.md`)
