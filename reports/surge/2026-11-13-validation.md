# surge の検証 2026-11-13

新しい売買システム `surge/` を作るときに行った検証の記録。数字は `reports/surge/backtest/2026-11-13-*/` にある
(`python -m surge backtest` / `robust` で作り直せる)。

## 前提
- 日足: Yahoo Finance、2003-06 〜 2026-11-12。配当込みの調整後価格。米国株は毎日の為替で円換算
- 母集団: 日米の大型株 258銘柄 (`surge/universe.yaml`)。**今の大型株の一覧なので、後知恵の偏りがある**
- 約定: 終値で判定し、次の営業日の寄付き。売った代金はその後に開く市場の買いにしか使えない
- 口座: 元手 40万円、整数株、片道コスト 0.2% (NISA の米国株は手数料・為替手数料 0 なので、値のずれの分)
- 「4か月後」は、検証期間のすべての日を起点にした 87営業日後のリターン (約5,500通り)

## 2. この数字の読み方

1. **「4か月で +20%」は5回に1回。** 指数 (20回に1回) の約4倍だが、3回に1回はマイナスで、8回に1回は -10% より悪い
2. **銘柄選びでリターンが増えているとは言えない。** 母集団を均等に持つだけで年 +20.1% で、surge (+20.8%) とほぼ同じ。
   母集団が「今の大型株」だから均等保有が強すぎる面はあるが、その中から選んでも上乗せはほぼない。
   既存の v3 の点検 (`reports/rules/2026-11-10-review.md`) と同じ種類の結果
3. **surge が変えているのは形。** (a) 5銘柄に集中するので、大きく勝つ4か月が増える (+20%以上が 12% → 21%)。そのぶん負ける4か月も増える。
   (b) 地合いのフィルターと売りのルールで、長い下げ相場の下落が小さい (2005〜2012年: 37% 対 53〜60%)
4. **これから先は、検証より悪いと考える。** 母集団の偏りに加えて、ルールも同じ21年を見て決めている (下の 3)

## 3. 設定の決め方

1つの設定の成績は偶然に大きく左右される (設計の最初の設定では、同時保有を 5 → 6 に変えるだけで 2026年が -7% から +12% になった)。
そこで、案の良し悪しは「同時保有 4・5・6・8銘柄 × 値上がり率の期間 4通り = 16通りの平均」で比べ、
一番成績の良い設定を選ぶことはしなかった。試した案は約60 (それぞれ16通り)。数字は年率 / 最大下落の16通り平均で、
設計の途中で比べたものなので、行ごとに期間やほかの設定が少し違う (同じ行の中では条件をそろえている)。

| 決めたこと | 根拠 |
|---|---|
| 指数が 200日線より下なら新規に買わない | 2013〜2026年だけ見ると、ない方が良い (38% / 51% 対 32% / 48%)。しかし設計に使っていなかった 2005〜2012年では、ないと 2% / 67%、あると 12% / 37%。長い下げ相場への備えとして入れる |
| 高値から 15% 以内の銘柄だけ買う | リターンは同じで、最大下落が 48% → 41%。落ちている途中の銘柄を「12か月ではまだ上位」という理由で買い直すのを防ぐ |
| 高値から -25% で売る + 35% 超えを減らす | リターンは 2〜3ポイント下がるが、最大下落が 48% → 40%。これがないと、2026年の急騰と急落 (キオクシアが +140% まで上がったあと、3か月で半値以下) で、検証上の資産が最高値から 55% 下がる設定があった |
| 米国株だけを買う | 日本株だけ: 12% / 59% (日本株の均等保有は 15%)。米国株だけ: 23% / 37% (米国株の均等保有は 22%)。日本株では順位づけが逆効果 |
| 売買代金が市場の上位 60% の銘柄だけ | 「今は大型株だが当時は小さかった」銘柄を過去の検証で買わないため。フィルターなしだと 2020〜2026年が年 +56% になるが、後知恵 |
| 入れ替えは毎週 | 2・4・8週ごとも、開始週をずらして平均すると差が小さい (毎週 32% / 2週 31% / 4週 30% / 8週 28%)。毎週なら「どの週に当たるか」の偶然がない |
| 買い増しで目標額にそろえる | 検証への影響はない (22.5% 対 22.6%)。今の保有を引き継ぐときに現金が余らないようにするため |

採用しなかった案: 値動きの大きさで割った順位づけ (21% / 43% で悪化) / 回帰の傾きでの順位づけ (差なし) / 直近1か月を外す (差なし) /
同じグループ1銘柄まで (リターン低下) / 値動きの大きい銘柄の金額を減らす (リターンと下落が同じ割合で下がるだけ。`vol_cap` として残してある) /
50日線・100日線割れで売る (売買が増えて悪化) / 持ち続ける順位を変える (差なし) / 上昇銘柄の割合で地合いを見る (差なし)。

設定を変えた16通りの幅 (最終の設定の周り): 年率 +18.7〜28.4% (平均 22.5%)、最大下落 34〜43% (平均 38%)、
4か月で +20% 以上 18〜27% (平均 21%)。どれを選んでも性質は同じ (`reports/surge/backtest/2026-11-13-full/robust.csv`)。

## 4. 検証と実際の違い

- **母集団の偏り**: 一番大きい。上場廃止や小型化した銘柄が入っていない
- **1株の値段**: 過去の価格は株式分割で小さく調整されているので、昔ほど「1株が高くて買えない」が起きにくい。
  直近の価格で 2022〜2026年に 40万円から 4か月を55回走らせた範囲では、整数株による不利はなかった (平均 +14% 対 端株ありの +12%)
- **約定**: 寄付きの価格で必ず約定する想定。決算の翌朝などは、判定に使った終値から大きく離れる
- **買付余力**: 売却代金がその日の米国の買いに使える想定。楽天で翌営業日になるなら、買いが1日遅れる (検証では3営業日まで待つ)
- **裁量**: Claude による買いの見送りは検証に入っていない

## 5. 見直しの目安

- 実際の成績を `reports/surge/journal.csv` に残し、月に1回、検証の幅と比べる
- 4か月で -17% より悪い、または最高値から -40% より悪い → 検証の範囲の外。`STOP` を置いて、続けるかどうかを人と決める
- ルールの数字を変えるときは、変える前に理由を書き、16通りの平均で比べる (1つの設定の成績で決めない)
