# surge と v3 を市場の状況で切り替えると良くなるか 2026-11-14

人からの問い: 「surge で行くとして、今がその時か。市場の状況を見て v3 と surge を切り替える仕組みでもいいのでは」。
`switch.py` で確かめた (結果は `result.json`、2つの仕組みの資産推移は `curves.csv`)。

## 方法
- surge と v3 を 2005-06 から 2026-11-13 まで通しで仮想売買し (各100万円、v3 の判定は日次と同じ現地通貨)、日々の損益を「合図」で選ぶ
- 合図は走らせる前に決めた5種類。数字を変えた版も全部出す (良いものを選ぶためではなく、考え方に中身があるかを見るため)
- 合図はその日の終値で判定し、2営業日後から切り替える。切り替えのたびに資産の 0.5% を引く

## 結果

| | 年率 | 最大下落 | シャープ | 4か月で +20% 以上 | 4か月でマイナス | 切り替えの回数 |
|---|---|---|---|---|---|---|
| surge だけ | +20.8% | 37.5% | 0.83 | 21% | 31% | — |
| v3 だけ | +12.3% | 26.5% | 0.92 | 4% | 28% | — |
| 半分ずつ持つ (切り替えなし) | +17.2% | 27.8% | 0.95 | 12% | 28% | — |
| S&P500 が 100 / 200 / 300日線より上なら surge | +14.3 / +16.7 / +18.3% | 39 / 45 / 39% | 0.66 / 0.72 / 0.77 | 17 / 19 / 19% | 40 / 36 / 33% | 244 / 143 / 119 |
| surge の資産が自分の 50 / 100 / 200日線より上なら surge | +7.0 / +9.0 / +14.2% | 46 / 57 / 42% | 0.40 / 0.48 / 0.65 | 13 / 17 / 18% | 46 / 44 / 39% | 384 / 262 / 172 |
| surge が最高値から 10 / 15 / 20% 以内なら surge | +15.8 / +10.6 / +14.8% | 33 / 45 / 35% | 0.78 / 0.54 / 0.67 | 13 / 15 / 18% | 33 / 38 / 36% | 140 / 176 / 140 |
| S&P500 の値動きが過去 126 / 252 / 504日の中央値より小さければ surge | +10.4 / +12.5 / +15.7% | 45 / 50 / 42% | 0.57 / 0.66 / 0.78 | 11 / 12 / 14% | 39 / 35 / 33% | 276 / 192 / 194 |
| 過去 63 / 126 / 252日のリターンが高い方を使う | +7.2 / +11.9 / +14.8% | 43 / 41 / 43% | 0.41 / 0.58 / 0.68 | 12 / 15 / 17% | 42 / 38 / 37% | 292 / 212 / 175 |

- **15通りの切り替えは、すべて「surge だけ」よりリターンが低く、すべて「半分ずつ持つ」よりシャープレシオが低い。** 最大下落も、ほとんどが surge だけより大きい
- 理由: (1) どちらの仕組みも、中に「指数が200日線より下なら買わない」を持っている。その外側にもう一段の合図を足しても、遅れて動くだけ。
  (2) surge の大きな上昇は、不調の直後に短い期間でまとまって来る。合図が戻るのを待っている間に取り逃す (11/10 の点検で、ドローダウン停止が成績を下げたのと同じ形)。
  (3) 切り替えのたびに全部売って全部買うコストがかかる
- 切り替えではなく **決まった割合で両方を持つ** のは意味がある (年率 +17%、最大下落は v3 だけとほぼ同じ 28%)。
  ただし 40万円の口座では、半分 (20万円) を5銘柄に分けると1株が買えない銘柄が多く、そのままは使えない

## 今がその時か

最新の日 (2026-11-13): S&P500 は 200日線の +2.9% 上。surge の検証上の資産は、2026年夏の最高値から -25.5%。

| いまと同じ状態の日から surge を始めた場合の4か月後 | 中央値 | +20% 以上 | マイナス | 逆の状態から始めた場合 |
|---|---|---|---|---|
| S&P500 が 200日線より上 (4,265日) | +7.0% | 22% | 31% | +2.4% / 16% / 30% |
| surge が最高値から 20% より深く下げている (1,859日) | +6.5% | 20% | 18% | +5.5% / 21% / 37% |
| surge の資産が自分の 100日線より下 (2,074日) | +7.2% | 24% | 22% | +5.2% / 19% / 36% |
| S&P500 の値動きが過去504日の中央値より大きい (3,010日) | +3.8% | 17% | 34% | +8.4% / 25% / 27% |
| S&P500 が 100日線より下 (1,448日) | +3.4% | 21% | 29% | +6.7% / 20% / 31% |

- **「いまは始めるのに悪い時期」という証拠はない。「特に良い時期」という証拠もない。** +20% に届く割合は、どの状態から始めても 16〜24% でほぼ同じ
- 下げた後 (最高値から -20% より深い) に始めた方が、マイナスで終わる割合は小さかった (18% 対 37%)。ただし深い下げは21年で数回しかなく、重なった期間を数えているので、強くは言えない
- 値動きの大きさは、504日の版ではいまが不利に見えるが、126日・252日の版では差がないか逆。一貫しないので合図として使えない
- 待って有利になる合図は見つからなかった
