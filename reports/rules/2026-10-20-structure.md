# ルールの組み立ての見直し 2026-10-20

`reports/rules/2026-10-20.md` の続き。パラメータの微調整ではなく、ルールの組み立てを変える案を3つと、その組み合わせを検証した。

- 条件は前回と同じ: 61銘柄、学習期間 2018-10〜2024-05 / 検証期間 2024-05〜2026-10、翌営業日の寄付きで約定
- 結果ファイル: `reports/backtest/2026-10-20-s*/`
- 新しく追加した機能: 市場フィルター (`entry.market_filter`)、年ごとの成績 (`yearly`)

## 試した案

| 案 | 変更 | 狙い |
|---|---|---|
| 1. トレンド崩れで売らない | `exit.trend_break: false` | 売買の回転を減らし、上昇の続きを取る |
| 2. 市場フィルター | 日経平均/S&P500 が SMA200 より下なら新規買いしない | 地合いが悪いときに買わない |
| 3. 分散 | 同時保有 5→8、1銘柄の目標 20%→12% | 1銘柄の値動きの影響を下げる |
| 4. 組み合わせ | 1+2+3 | |

## わかったこと

1. **案3・案4は基準を満たした。** 主な効果は「下落の幅が小さくなる」こと (案4: 最大下落 37%→28%、2022年の下げ相場で +2%)
2. **ただし、どの案も検証期間 (2024/5〜) は横ばい〜マイナスで、指数を持っているだけ (+55%) に大きく負けている。** 学習期間で指数に勝った案1・案4も、直近2年半は勝てていない
3. **ここ2年半は、個別株を入れ替える売買そのものが報われていない。** ルールの細部を直しても指数との差は埋まらない
4. **検証期間を見るのは今日で7回目。** 回数を重ねるほど、検証期間でたまたま良かった案を選ぶ危険が増える。今後の判断は、これから先の実際の成績で確かめるのが確実

## 人に判断してほしいこと

**A. 売買ルールを案4 (組み合わせ) に切り替える**
下落の幅を抑える効果は学習・検証の両方で確認できた。ただし指数には負けている。
切り替えると、明日からの東京エレクトロン・VRT の「トレンド崩れ」の売りシグナルは出なくなる (損切り・トレーリングの基準は今日の価格なので、すぐには出ない)。

**B. 口座の作りを「コア・サテライト」に変える**
- コア: 口座の大半を指数 (日経平均・S&P500 などの投資信託や ETF) で持つ
- サテライト: 一部だけをこのシステムで売買する
- 検証結果からは、これが一番素直な結論。ただし今の個別株を大きく入れ替えることになり、税金 (含み益のある MSFT など) や NISA 枠の扱いも絡むので、人が決めること

**C. 今の v1 のまま様子を見る**
検証結果からはおすすめしない。

A と B は両立できる (サテライト部分のルールを案4にする)。
