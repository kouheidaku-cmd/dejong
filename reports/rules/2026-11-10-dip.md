# AI 半導体株の押し目買い (急落後の反発狙い) の検証 2026-11-10

手順・対象銘柄・候補・採用の基準は、検証の前に `rules/candidates/PROTOCOL-2026-11-10.md` に書いてコミットした (8a312c8)。
結果を見た後で、仕様と基準は変えていない。
結果ファイル: `reports/backtest/2026-11-10-dip-events/` (前提の確認)、`reports/backtest/2026-11-10-dip-yearly/` (年ごと)、
`reports/backtest/2026-11-10-{v3,d1-dip15-trend,d2-dip25,d3-dip15}-split/` (学習 / 検証)。

## 結論

- **採用候補はなし。** 3案とも8年通算のリターンは v3 より増えた (+112% → +139〜175%) が、**下落も増えて、事前に決めた下落の基準を満たさなかった**
- **「下がったあとは必ず上がる」は、過去のデータでは正しくない。** 2019年以降の AI 半導体17銘柄でも、急落の60営業日後にプラスだったのは 65〜68% で、
  急落と関係なく「いつ買っても」の 66% と変わらない。上がったのは急落したからではなく、この銘柄群がこの期間ずっと上がっていたから
- **今まさに外れている最中。** 半導体指数 (^SOX) は 2026年6月の高値から -31%。2026年7月以降の押し目買いは、3案とも 23回買って勝ちは 5〜7回、
  損失は -8.6万〜-16.3万円 (100万円から始めた検証期間の口座で)。-12% の損切りのはずが、実際の損失は -23〜-27% になった売りが続いた (翌朝の寄付きまでにさらに下げたため)
- **実際の口座は v3 のまま。** 一番基準に近かった d1 (上昇トレンドの中の -15% の押し目) を、参考としてフォワードテストに足した (`config/forward.yaml`)

## 1. 前提の確認: 急落のあと、どうなったか

急落 = 終値が直近120営業日の最高終値から 15% / 25% 以上下げた状態に**なった日** (同じ銘柄は60営業日以上あけて数える)。2019年〜2026-11-10、17銘柄、現地通貨。

| その日の終値で買ったとして | -15% になった日 (233回) | -25% になった日 (147回) | いつ買っても (比較) |
|---|---|---|---|
| 20営業日後にプラスの割合 / 中央値 | 57% / +3.7% | 58% / +2.6% | 61% / +3.1% |
| 60営業日後 | 65% / +10.1% | 68% / +12.2% | 66% / +9.0% |
| 120営業日後 | 75% / +26.4% | 74% / +27.8% | 73% / +20.5% |
| 250営業日後 | 73% / +47.9% | 81% / +54.2% | 78% / +43.4% |
| 60営業日後の下位10% | -17.0% | -18.2% | -17.0% |
| その後120営業日でさらに下げた幅 (中央値 / 下位10%) | -10.8% / -34.5% | -14.1% / -37.5% | |
| 250営業日以内に元の高値を回復した割合 | 81% | 70% | |

読み方:
- **急落の後のリターンは「いつ買っても」とほぼ同じ。** プラスになる割合は急落の後のほうが高いとは言えない (60営業日後で 65〜68% 対 66%)。中央値は少し高いが、差は小さい
- **急落した日はたいてい底ではない。** 半分以上の場合で、そこからさらに 10〜14% 下げている。10回に1回は、さらに 35% 前後下げている
- **元の高値に1年以内に戻らなかった場合が 2〜3割ある**

もっと長い期間で見ると (参考、同じスクリプト):

| | 最高値を回復できなかった最長の期間 | その間の最大の下落 |
|---|---|---|
| 半導体指数 (^SOX) | 17.7年 (2000-03 〜 2017-11) | -87% |
| Intel | 25.6年 (2000-09 〜 2026-04) | -84% |
| NVIDIA | 8.6年 (2007-10 〜 2016-05) | -85% |

- 2016年以前の半導体指数では、-15% の急落 (29回) の60営業日後にプラスだったのは 45%、250営業日以内に高値を回復したのは 45%。-25% の急落 (17回) では高値の回復は 29%
- つまり「下がったら戻る」が成り立っていたのは 2019年以降の上昇相場の話で、半導体株そのものの性質ではない

## わかったこと

1. **リターンは増えた。ただし「急落を当てた」からではない。** 別枠は8年のうち d1 が5年、d2 が4年、d3 が7年でプラスだったが、前提の確認で見たとおり、急落の後のリターンは「いつ買っても」と変わらない。
   利益の元は、値動きの大きい AI 半導体株を、上昇相場の間に多く持ったこと。同じことは下げ相場では損失を大きくする (2022年は3案とも v3 より 5〜8ポイント悪い)
2. **下落が大きくなる。** 各年の最大下落の平均は 14.7% → 16.8〜17.2%。検証期間 (直近2年半) の最大下落は 26% → 30〜34%。
   実際の口座は最高値から -15% で新規買いが止まる (`settings.yaml`) ので、この大きさの下落は運用上も重い
3. **長期トレンドの条件 (200日線より上) は効いている。** 条件のない d2・d3 は、2022年と今回の下げで買いと損切りを繰り返した (2022年の売買は d1 の16回に対し 30〜32回)。
   深い急落 (-25%) だけを狙う d2 は検証期間でほとんど稼げず (+7,763円)、2026年は -10万円。「大きく下げたものほど戻る」は確認できなかった
4. **検証期間の別枠の利益は、ほぼ1銘柄で決まっている。** d1 の検証期間の +10.4万円のうち +10.2万円が MRVL。学習期間は1銘柄を除いてもプラスだが、直近は心もとない
5. **損切りは -12% で止まらない。** 2026年10〜11月の損切りは、実際の損失が -23% (MRVL)、-26% (Intel)、-25% (アドバンテスト)、-27% (レーザーテック)。
   終値で判定して翌朝の寄付きで売るので、急落の最中は売るまでにさらに下げる。1回の損失を総資産の約1%に抑える設計は、急落時には約2%になった
6. **今は押し目買いが一番外れている時期。** 2026年7月以降に買った分は、3案とも 23回で勝ち 5〜7回、損益は d1 -163,487円 / d2 -86,349円 / d3 -131,306円 (100万円から始めた検証期間の口座で)

## 注意
- **対象の17銘柄は「今 AI 半導体として知られている銘柄」。後から見て勝った銘柄に偏っている** ので、過去の成績は実力より良く見える (Intel を入れても偏りは残る)
- 2019〜2026 は半導体株が大きく上がった時期。上の「長い期間」の表のとおり、戻らなかった時代もある
- 検証は100万円。実際の口座 (約40万円) では 8% = 約3.2万円で、11/10 時点で1株以上買えるのは17銘柄中8銘柄
  (NVDA・MRVL・KLAC・ARM・Intel・東京エレクトロン・アドバンテスト・キオクシア)。AMD・AVGO・TSMC・Micron・ASML・AMAT・Lam・ディスコ・レーザーテックは買えない
- 別枠の買いは市場フィルターを通らない。実際の口座ではドローダウン停止 (-15%) が先に働く場合があるが、検証には入っていない

## 提案
- **ルールは v3 のまま変えない** (基準を満たす候補がないため)
- **d1 をフォワードテストに参考として足す** (`config/forward.yaml`)。momentum-12-1・swap-gap20 と同じ扱い (リターンは増えたが下落の基準が未達)。
  2027年1月下旬の見直しで、実データでの成績を v3 と比べる
- 人の判断で採用する場合 (v2 のときと同じ) に必要なこと。仕組みはコードに入っているので、設定と手順の変更だけで動く:
  1. `config/rules.yaml` に候補の `sleeves` を写し、`version` を上げて `rules_changelog.md` に記録する
  2. `config/strategy.md` に別枠の説明を足す (今は「シグナルのない買い / ナンピン」を禁じている。別枠はシグナルによる買いで、同じ銘柄の買い増しはしない)
  3. 買いたい対象銘柄を週次リサーチで `watchlist.yaml` に載せる (ウォッチリスト外は買えない)
  4. daily-trade の手順に「`sleeve` の付いた買い候補は `sleeve_slots` の数まで。注文に `"sleeve": "dip"` を付け、約定の記録は `record --sleeve dip`」を足す
- 採用するなら d1 (長期トレンドの条件つき)。d2・d3 は下げ相場での損失が大きく、勧めない
